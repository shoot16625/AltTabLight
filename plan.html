AltTab macOS メモリ軽量化計画

作成日: 2026-06-25 | 対象: ~450MB (Mac Pro) のメモリ使用量削減

根本原因: アプリが非表示の間も、全ウインドウのサムネイル（非圧縮 BGRA/IOSurface）とアプリアイコンがメモリ上に保持され続ける。
推定内訳: サムネイル ~60-75%、アプリアイコン ~10-15%、その他キャッシュ ~10-15%

現状分析

1. サムネイルの保持（最大の原因）

箇所内容メモリ影響
src/switcher/state/Window.swift:21 var thumbnail: CALayerContents? — 全 Window オブジェクトが非圧縮の CGImage / CVPixelBuffer を保持 大: Retina 2880x1800 x 4bytes = ~20MB/枚 x 50枚 = ~1GB
src/switcher/state/WindowThumbnails.swift:22-42 refreshAsync が全ウインドウにサムネイル取得をディスパッチ スイッチャー表示時、画面外のウインドウも全件取得
src/events/WindowCaptureEvents.swift:305-308 プレビュー有効時、全サムネイルをフル解像度で取得（retina 実サイズ） 致命的: 1ショートカットでもプレビュー有効だと全サムネイルが最大サイズに
src/App.swift:287-288 refreshOpenUiAfterExternalEvent で外部イベント毎にサムネイル再取得 ウインドウの移動/リサイズのたびに新しい IOSurface を確保

2. サムネイルがスイッチャー非表示時に解放されない

hideUi()（src/App.swift:63-79）ではパネルを隠すのみで、Window.thumbnail や TileView の contents は解放しない。

スイッチャーは通常ユーザが一瞬だけ見る UI。にもかかわらずサムネイルはアプリ終了まで保持され続ける。

3. アプリアイコンがフル解像度で常駐

箇所内容
src/switcher/state/Application.swift:20 var icon: CGImage? — 全アプリのアイコンを保持（50-100個）
src/switcher/state/Application.swift:61-79 appIconWithoutPadding — 最大画面サイズでレンダリングされた高解像度 CGImage

4. キャッシュの無制限成長

箇所内容
src/preferences/Preferences.swift:433 CachedUserDefaults.cache — ConcurrentMap が全 UserDefaults 値を無限キャッシュ。設定画面を開くまで削除されない
src/events/WindowCaptureEvents.swift:9 cachedSCWindows — SCWindow オブジェクトが蓄積。ウインドウ削除時のみ削除
src/App.swift:17 CGImage.allNamed("app.icns") — icns ファイルの全フレームを起動時に読み込み

計測と検証方法

  1. Xcode Memory Debugger: 各フェーズ後、ヒープ全体のスナップショットを取得
  2. Allocations Instrument: サムネイル/CGImage/IOSurface のライブアロケーション数とサイズを追跡
  3. VM Tracker: 物理メモリと仮想メモリの使用量変化を確認
  4. 手動テスト: 50+ ウインドウを開いた状態でスイッチャー表示/非表示を繰り返し、メモリ使用量を確認
  5. 既存のビルド: ai/build.sh でコンパイル確認 + ユニットテスト通過確認

リスクと注意点

  • #1 のトレードオフ: スイッチャー非表示→再表示時に全サムネイル再キャプチャが発生。表示が一瞬遅くなる（通常 100-300ms）。プレビュー選択中ウインドウだけは保持するなどの最適化も検討可能
  • #4 のトレードオフ: JPEG/HEIC 圧縮は CPU 負荷とのトレードオフ。毎秒のキャプチャ更新時に常に圧縮処理が走る。HEIC ハードウェアエンコード対応の Apple Silicon では影響軽微
  • リークの再発防止: releaseThumbnail() など新しい解放パスがリークにならないよう deinit でも安全に動作することを確認
  • Space 切り替え時の動作: サムネイル解放後に Space を切り替えて戻ってきた時、サムネイルが正しく再取得されることを確認
  • keychain/license 不変性: License / Keychain のコードには一切触れない（AGENTS.md の制約）
